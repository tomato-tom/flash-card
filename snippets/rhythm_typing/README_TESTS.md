# リズムタイピング - テストスニペット

## 概要
元のスクリプトを5つのテストスニペットに分割。各機能を個別に検証可能。

## テストファイル一覧

### test01_fifo_basic.sh
**目的**: FIFO通信の基本動作確認  
**テスト内容**:
- FIFOの作成と削除
- キー入力のFIFO経由での送受信
- バックグラウンドプロセスとの通信

**実行方法**:
```bash
chmod +x test01_fifo_basic.sh
./test01_fifo_basic.sh
```

**期待動作**:
- キーを押すと受信メッセージが表示される
- 'q'で終了

---

### test02_render_header.sh
**目的**: 画面描画とヘッダー表示  
**テスト内容**:
- 画面クリアと再描画
- スコア/ミス/残り時間の表示
- ターゲットラインの描画

**実行方法**:
```bash
chmod +x test02_render_header.sh
./test02_render_header.sh
```

**期待動作**:
- ヘッダーが表示される
- スコアとミスが毎秒更新される
- 10回更新後に自動終了

---

### test03_char_animation.sh
**目的**: 文字の生成と移動アニメーション  
**テスト内容**:
- 配列による文字管理
- 左方向への移動
- 画面外判定

**実行方法**:
```bash
chmod +x test03_char_animation.sh
./test03_char_animation.sh
```

**期待動作**:
- 文字'a'が3つ生成される
- 右から左に移動
- 画面外に出ると消える
- デバッグ情報が表示される

---

### test04_hit_detection.sh
**目的**: タイミング判定ロジック  
**テスト内容**:
- ターゲット位置との距離計算
- ±3以内の判定
- 最も近い文字の選択
- スコア計算

**実行方法**:
```bash
chmod +x test04_hit_detection.sh
./test04_hit_detection.sh
```

**期待動作**:
- 様々な位置の文字で判定テスト
- ヒット/ミスの判定結果表示
- スコアの加算/減算

---

### test05_simple_integration.sh
**目的**: 簡易統合テスト  
**テスト内容**:
- 移動、描画、判定の統合
- 手動キー入力での動作確認
- ゲームループの基本動作

**実行方法**:
```bash
chmod +x test05_simple_integration.sh
./test05_simple_integration.sh
```

**期待動作**:
- 文字が右から左に流れる
- 'a'キーでタイミング判定
- スコアとミスがカウントされる
- 'q'で終了

---

## 各機能の対応表

| 機能 | 元の関数 | テストファイル |
|------|----------|----------------|
| FIFO通信 | key_input_handler | test01 |
| 画面描画 | render_screen | test02 |
| 文字管理 | animation_handler (文字生成・移動部分) | test03 |
| 判定処理 | process_key_input | test04 |
| 統合動作 | メインループ | test05 |

## 統合時の注意点

1. **FIFO処理**: test01で動作確認後、本番では非同期処理として統合
2. **描画最適化**: test02,03の描画を統合、ちらつき対策
3. **タイミング調整**: test05で全体のバランス調整
4. **エラーハンドリング**: 各テストで問題なければ、cleanup処理を統合

## 次のステップ

各テストが正常動作したら:
1. test05をベースに本番統合
2. バックグラウンドプロセス化
3. エラーハンドリング強化
4. パフォーマンス最適化
