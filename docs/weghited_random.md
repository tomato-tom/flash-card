# 重み付けランダム選択

gemini web

flash_card.sh より
```
# priorityに基づく重み付け抽出
RAW_DATA=$(jq -c '.content[]' "$VOCAB_JSON" | awk -F: '{
    split($0, a, "\"priority\":"); split(a[2], b, ","); 
    p=b[1]*10; for(i=0; i<p; i++) print $0 
}' | shuf -n 1)
```

この部分は、**「苦手な単語（Priorityが高い単語）ほど、抽選箱の中にたくさん入れる」**という物理的な「くじ引き」の仕組みをコードで再現しています。

ホビー開発で便利な、`jq`、`awk`、`shuf` を組み合わせたワンライナーの動きを分解して説明します。

---

### 処理の3ステップ

#### 1. `jq -c '.content[]' "$VOCAB_JSON"`

* **何をしているか**: JSONの配列をバラして、1カード1行の文字列に変換します。
* **出力イメージ**:
```text
{"card-id":"w-001","english":"tomato",...,"priority":1.0}
{"card-id":"w-002","english":"redundant",...,"priority":1.5}

```

#### 2. `awk -F: '{ ... }'`

ここが重み付けの核心部です。`priority` の数値分だけ、その行を**複製**（リピート）して出力します。

* **`split($0, a, "\"priority\":")`**: 1行のデータ（`$0`）を `"priority":` という文字列で分割し、右側の数値部分を取り出せるようにします。
* **`p=b[1]*10`**: `priority` が `1.5` なら、10倍して `15` という整数にします。
* **`for(i=0; i<p; i++) print $0`**:
* Priority 1.0 の単語（普通）なら **10回** `print` する。
* Priority 1.5 の単語（苦手）なら **15回** `print` する。


* **結果**: 出力される全行の中で、苦手な単語が占める「行数（確率）」が増えます。

#### 3. `| shuf -n 1`

* **何をしているか**: 複製されて増えた大量の行の中から、ランダムに **1行だけ** をピックアップします。
* **効果**:
* 15枚入っている「苦手カード」は、10枚しか入っていない「普通カード」よりも **1.5倍当たりやすく** なります。



### 💡 なぜこの方法か

* **シンプル**: 複雑な確率計算アルゴリズムを書かなくても、`shuf` に任せるだけで直感的な重み付けができます。
* **拡張性**: もし「もっと苦手な単語を強調したい」なら、`p=b[1]*20` のように倍率を上げるだけで調整可能です。
