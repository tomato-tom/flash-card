# Flash Card とTyping game

英語の単語・フレーズ学習用

## フラッシュカード
```
$ ./flash_card.sh
```

統計表示
```
$ ./flash_card_stats.sh
```

## タイピングゲーム
```
$ ./typing.sh
```
> 今の所/usr/bin /usr/sbinから

統計
```
$ ./typing_stats.sh
```
